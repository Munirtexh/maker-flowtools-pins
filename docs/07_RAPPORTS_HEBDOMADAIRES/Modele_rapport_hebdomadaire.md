# Rapport hebdomadaire (lundi–dimanche), à lire le lundi
Par plateforme: Facebook · Instagram · Pinterest · Etsy (public). Pour chacune:
- Faits mesurés (abonnés, vues, partages, enregistrements, clics) — sinon « données indisponibles ».
- Meilleur et pire contenu, publications manquées, erreurs.
- Hypothèses (marquées comme telles).
Synthèse globale: meilleur réseau, meilleur contenu, contenus faibles, tests à lancer, 3 actions prioritaires, tâches pour toi.
