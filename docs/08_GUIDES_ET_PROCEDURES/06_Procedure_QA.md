# Contrôle qualité avant chaque publication
1. Orthographe et ton (FR du Québec / EN simple).
2. Lien et image répondent HTTP 200.
3. Format: reel 1080×1920, carte 1080×1350, pin 1000×1500; couverture présente pour les reels.
4. Aucune affirmation trompeuse: pas de rabais, d'avis, de chiffres de ventes ou de promesses de résultat.
5. Droits: visuels et musique créés pour la marque; aucune musique tierce.
6. Produit non publié (Kit Trésorier): la tâche saute le post tant que la fiche n'est pas en ligne sur la boutique.
7. Aucune republication si un post avec la même légende existe déjà dans les dernières 24 h.
Rapports: toute erreur est inscrite telle quelle dans le rapport du lundi; « données indisponibles » quand un chiffre n'existe pas.
